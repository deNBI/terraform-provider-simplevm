# terraform-provider-simplevm

Terraform and OpenTofu provider for [SimpleVM](https://simplevm.denbi.de/), the de.NBI Cloud portal for virtual machines. Describe VMs, research environments, volumes and snapshots as code and manage them with `tofu apply` or `terraform apply`.

- Resources: `simplevm_vm`, `simplevm_volume`, `simplevm_volume_attachment`, `simplevm_snapshot`
- Data sources: projects, flavors, images, snapshot images, VMs and volumes
- Works with OpenTofu 1.6+ and Terraform 1.5+

Not supported: clusters (BiBiGrid) and member management; use the SimpleVM portal for those.

## Usage

```hcl
terraform {
  required_providers {
    simplevm = {
      source = "deNBI/simplevm"
    }
  }
}

provider "simplevm" {} # SIMPLEVM_API_KEY and SIMPLEVM_PROJECT_ID from the environment

resource "simplevm_vm" "analysis" {
  name   = "analysis"
  flavor = "de.NBI default"
  image  = "Ubuntu 22.04"
}
```

You need a SimpleVM API key (a beta feature, available on request) with the scopes `project:read`, `vm:read`, the VM and volume change scopes, and `volume:change_state`. See the [user guide](wiki/simple_vm/opentofu.md) for a walkthrough and recipes, and the [reference documentation](docs/index.md) for all arguments.

The provider is not published to the registries yet. Once released, `tofu init` / `terraform init` installs it. Until then, build it locally and use `dev_overrides` as described in [development/testing.md](development/testing.md).
